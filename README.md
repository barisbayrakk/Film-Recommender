# 🎬 Film Öneri Platformu

---

Bu proje, kullanıcıların film tercihine göre öneriler almasını sağlayan modern bir **Film Öneri Platformudur**.

-  Film keşfetme
-  Favorilere ekleme
-  Akıllı öneri sistemi
-  Chatbot destekli öneriler

---

##  Özellikler

-  Film listeleme ve keşfetme  
-  Gelişmiş arama ve filtreleme  
-  Favori filmleri kaydetme, puanlama
-  Yapay zeka destekli öneri sistemi  
-  Chatbot (FilmRec Asistan)  
-  Admin paneli  
-  İstatistik ve analiz ekranı  

---

##  Kullanılan Teknolojiler

| Teknoloji | Açıklama |
|----------|--------|
|  Python | Backend |
|  MySQL | Veritabanı |
|  React | Frontend |
